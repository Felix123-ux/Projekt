## Tech stack
- TypeScript, CSS, HTML
- ZOD for TypeScript
- NPM as package manager
- Biome for formatting and linting
- Prefer solutions without additional packages. Always ask before installing packages.

## Workflow
- Run a build after completing a task to check for errors.
- Run "npm run check" after completing a task and fix all biome errors.
- Exception: Do not run check and build, if you only added or changed a comment.
